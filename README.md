# Interactive Video Cut-out Tool

## Overview
An AI-powered computer vision application for interactive object segmentation and background removal from videos using the Segment Anything Model (SAM).

## Features
- Video Upload
- Frame Extraction
- Object Segmentation
- Mask Generation
- Background Removal
- Video Reconstruction

## Tech Stack
- Python
- FastAPI
- OpenCV
- Segment Anything Model (SAM)
- CUDA
- HTML
- CSS
- JavaScript

## Architecture
- Backend: FastAPI
- AI Model: Segment Anything Model (SAM)
- Dataset: DAVIS
- Processing: OpenCV, CUDA
